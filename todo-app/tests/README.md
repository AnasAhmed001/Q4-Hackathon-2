# Tests

This directory contains test files for the todo application.

## Running Tests

Run all tests:
```bash
python -m tests.test_todo_app
python -m tests.test_validate
```

Or run directly:
```bash
cd tests
python test_todo_app.py
python test_validate.py
```

## Test Files

- `test_todo_app.py` - Functional tests for all todo operations
- `test_validate.py` - Validation tests for requirements compliance
