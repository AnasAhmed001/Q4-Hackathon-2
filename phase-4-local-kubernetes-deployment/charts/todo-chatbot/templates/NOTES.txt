Phase IV — Todo Chatbot is installed in namespace {{ .Release.Namespace }}.

  1. Make sure the cluster's published ports are up (T033):
       minikube start --driver=docker --cpus=4 --memory=4096 --ports=30080:30080,30800:30800
     If the driver rejects --ports, use the documented port-forward fallback:
       kubectl -n {{ .Release.Namespace }} port-forward --address 127.0.0.1 svc/{{ include "todo-chatbot.fullname" . }}-frontend 30080:3000
       kubectl -n {{ .Release.Namespace }} port-forward --address 127.0.0.1 svc/{{ include "todo-chatbot.fullname" . }}-backend  30800:7860

  2. Open the application:
       Frontend  ->  http://localhost:30080
       Backend   ->  http://localhost:30800/health

  3. Check status:
       kubectl -n {{ .Release.Namespace }} get pods
